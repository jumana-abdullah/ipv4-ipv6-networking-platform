# 🌐 Understanding IPv4 and IPv6 Addressing Platform

A comprehensive educational web platform developed as part of the Computer Networks course at Taif University (Al-Khurma University College, Section 286).

## 🚀 Features
- **Interactive Calculators:** Built-in tools for IPv4 subnetting and IPv6 prefix calculations (/64 SLAAC standard).
- **IP Lookup & Analysis Tool:** Instant validation and deep analysis of network addresses (Public vs. Private, Class detection).
- **Dynamic Quiz System:** Interactive knowledge challenges with real-time feedback and score tracking.
- **Admin Dashboard:** Secure MySQL-backed management portal supporting full CRUD operations for quiz questions (Protected with PHP Sessions and authentication).

## 💻 Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Tools:** Cisco Packet Tracer (for network topology simulation and verification)
